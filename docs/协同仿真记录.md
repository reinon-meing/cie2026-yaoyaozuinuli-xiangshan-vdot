# 协同仿真记录（对应官方 3.1.2）

> 目标：验证 RTL 中新增的 vdot.vv 与 NEMU 参考模型的同语义实现逐指令一致。
> 方式：emu 带 `--diff` 指向**本作品补丁重建的** `riscv64-nemu-interpreter-so`，每条指令提交后比对整数/向量寄存器与内存。

## 1. 参考模型

```bash
cd $NEMU_HOME
make riscv64-xs-ref_defconfig
make -j$(nproc)
# 产物：build/riscv64-nemu-interpreter-so
```

补丁见 [patches/02-nemu-vdot.patch](../patches/02-nemu-vdot.patch)（3 文件 +32/−1）。

## 2. 运行方式

```bash
cd $NOOP_HOME
REF=$NEMU_HOME/build/riscv64-nemu-interpreter-so

timeout 600 ./build/emu-diff \
  -i $AM_HOME/apps/vdottest/build/vdottest-riscv64-xs.bin \
  --diff $REF 2>&1 | grep --line-buffered -av PERF
```

> 注意：必须用自建参考模型；`ready-to-run/` 下的官方 `.so` 不认识 vdot，会报非法指令。

## 3. 结果

| 测试 | 用例数 | 结果 | mismatch | 日志 |
|---|---:|---|---:|---|
| vdottest（正/负/边界） | 11 | `VDOT RESULT: 11/11 PASSED` | 0 | [diff_vdottest.log](logs/stage3/diff_vdottest.log) |
| vdot_sew_test（SEW） | 5 | `VDOT SEW RESULT: 5/5 PASSED` | 0 | [vdot_sew_test.log](logs/stage3/recheck2/vdot_sew_test.log) |
| vdot_edge_test（边界） | 4 | `VDOT EDGE DONE` | 0 | [vdot_edge_test.log](logs/stage3/recheck2/vdot_edge_test.log) |
| hello 回归 | 1 | `Exit with code = 0` | 0 | [diff_hello.log](logs/stage3/diff_hello.log) |
| vaddtest 回归 | 1 | `Exit with code = 0` | 0 | [diff_vaddtest.log](logs/stage3/diff_vaddtest.log) |

所有日志中均未出现 `mismatch` / `ABORT` / `different` 行。

## 4. 说明

- `timeout` 返回 124 属正常：AM 的 `_halt` 打印 `Exit with code = 0` 后进入 `while(1)`，仿真不会自行退出；
- 功能/difftest 用 `emu-diff`；波形 dump 用带 trace 的 `emu-wave`（原因见 [操作手册 §11](操作手册.md)）；
- 复检时间：2026-11-05（见 `logs/stage3/recheck2/`）。

## 5. 结论

RTL 与 NEMU 在 vdot.vv 上**逐指令一致，零 mismatch**；SEW≠8 时两侧一致地抛非法指令异常。
