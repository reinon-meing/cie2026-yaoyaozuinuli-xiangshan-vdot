# 功能测试报告（对应官方 2.3.1–2.3.3）

> 环境：Ubuntu 24.04 · Verilator 4.218 · emu（RTL 16ae9ddcd + vdot 补丁）
> 判定：vd 低 4 字节（小端 int32）等于期望值，且其余 12 字节全为 0。
> 日志：[docs/logs/vdot_11cases.log](logs/vdot_11cases.log)；程序：[scripts/vdottest/](../scripts/vdottest/)。

## 2.3.1 正数点积

| 用例 | 输入（前 8 字节） | 期望 | 实测 | 尾部清零 | 结果 |
|---|---|---:|---:|---|---|
| pos-ramp | a=1..8, b=8..1 | 120 | 120 | 是 | PASS |
| pos-uniform | a=3×8, b=5×8 | 120 | 120 | 是 | PASS |
| pos-with-max | a=127×8, b=1×8 | 1016 | 1016 | 是 | PASS |

## 2.3.2 负数点积

| 用例 | 输入（前 8 字节） | 期望 | 实测 | 尾部清零 | 结果 |
|---|---|---:|---:|---|---|
| neg-mixed-sign | a=-1..-8, b=1,-2,3,-4,5,-6,7,-8 | 36 | 36 | 是 | PASS |
| neg-nonuniform | a=-128,127,-100,100,-1,1,-2,2 等 | -204 | -204 | 是 | PASS |
| neg-all-neg | a=-128,-127,-1..-6, b=-1×8 | 276 | 276 | 是 | PASS |

## 2.3.3 边界值点积

| 用例 | 输入（前 8 字节） | 期望 | 实测 | 尾部清零 | 结果 |
|---|---|---:|---:|---|---|
| bnd-max-positive | -128×8 与 -128×8 | 131072 | 131072 | 是 | PASS |
| bnd-max-negative | 127×8 与 -128×8 | -130048 | -130048 | 是 | PASS |
| bnd-127-squared | 127×8 与 127×8 | 129032 | 129032 | 是 | PASS |
| bnd-zero | 全 0 与全 0 | 0 | 0 | 是 | PASS |
| bnd-tail-ignored | 第 9..16 字节全 127，前 8 字节全 1 | 8 | 8 | 是 | PASS |

**11/11 PASS**。

## 附加：SEW 与边界测试

### SEW 用例（5 个，vdot_sew_test）

| 用例 | 期望 | 结果 |
|---|---|---|
| SEW=8 正常执行 | 120、尾部清零、无陷阱 | PASS |
| SEW=16 | 触发非法指令（mcause=2） | PASS |
| SEW=32 | 触发非法指令 | PASS |
| 被陷阱打断的 vdot | vd 保持 0x5a，不写回 | PASS |
| 陷阱后回到 SEW=8 | 仍为 120 | PASS |

### 边界用例（4 个，vdot_edge_test）

| 用例 | 结果 |
|---|---|
| LMUL=2（对齐 v2 组） | 低 128 位 120；组内第二寄存器未被写 |
| vd == vs1 | 120 |
| vl = 0 | 未定义行为（输出 0x3c0，不承诺写回） |
| vstart = 4 | 120（整寄存器写回，与 vstart 无关） |

日志：[docs/logs/stage3/vdot_edge_test.log](logs/stage3/vdot_edge_test.log)。
